## Processing steps

1. To obtain the anchored Covariates, perform the anchoring using the hive directory in D3_Study_Variables.
2. Merge the Covariates with D4_Study_Cohort using as key `person_id`. This will help obtain the following variables: `eligible_exposed`, `eligible_control`, `group`
3. Create the variable `group_unmatched` as explained above.
4. Retrieve/create the rest of the variables as describe in the codebook.
