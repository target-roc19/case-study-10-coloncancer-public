## Metadata

| Table name                | D3_ELIGIBILITY                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Description               | A data object which defines which members of the source population are eligible vs non-eligible for entry into the cohort (base on study variable information). To be eligible you must meet all inclusion (and no exclusion) criteria on at least one calendar date in the study enrollment period. As well as dates and inclusion/exclusion info, this object contains information on any and all matching variables to be used. This is used as input for the cohort selection (matching) process. |
| Source                    | data/D3_study_variables/D3_MULTIVARIATE_EPISODES_parquet                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Step                      | transformations/T3_study_design/source_code/calculate_eligibility.R                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Content                   |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Population                | All individuals who are registered in the Dutch NCR who have observations that fall within the study period (01/01/2015 until 31/12/2015 and 01/01/2021 until 31/12/2021), and are potentially eligible.                                                                                                                                                                                                                                                                                              |
| Unit of Observation (UoO) | Spell/status: period of time within a person during which eligibility is ascertained for exposed or control status, and some covariate profile is fixed.`<br>`One or more rows per person (key: person_id, start_episode)                                                                                                                                                                                                                                                                             |
