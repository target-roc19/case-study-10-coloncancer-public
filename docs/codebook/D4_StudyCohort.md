## Study cohort selection process

First, from D3_ELIGIBILITY we select all individuals with eligible_exposed = TRUE or eligible_control = TRUE.
Matching is feasible **only** if both groups each have at least 220 patients. The matching is done using SV_ECOG_STATUS and SV_METASTASIS_LIVER .
**The matching is 1:1 matching without replacement.**

### Note:

Additionally, we saved the rest of the variables the were part of D3_ELIGIBILITY such as "SV_AGE_18_OR_OLDER", "SV_BEVACIZUMAB", SV_CRC_DIAGNOSIS" etc. Since those are not used in this step, and are just carried/retrieved from D3_ELIGIBILITY, we did not mentioned them above. For more information and description on those variables, please check codebook D3_ELIGIBILITY.md.
