## Processing Steps

1. `create_simple_concepts` selects records from D2_CDM using the codelists (`MERGED_CODELISTS.csv`) and `dap_specific_concept_map.csv`, and writes one partition per concept_id.
2. `create_complex_concepts` derives further concepts from those partitions following `concept_preprocessing.csv`. The functions used are `create_or` (any sub-concept present), `create_and_samedate` (all sub-concepts on the same date), `apply_concept_meaning` (map sub-concepts to the values in `concept_meaning.csv`), `select_first_record` (earliest record per person), `is_18_or_older` (birth_date + 18 years, from D3_SPELLS) and `is_below_1` (value < 1).

Note: `value` and `date` are not stored with the same type in every partition, because the concept functions write different types. Read a single partition rather than the whole folder when the type matters.
